확실한 문제

코드를 따라가 외부 입력이 취약한 지점에 닿는 경로를 확인했고, 별도 검증이 반박하지 못한 것. 바로 고치세요.

추가 확인 필요

가능성은 있지만 실행 환경을 봐야 알 수 있는 것. 무엇을 확인해야 하는지 정확히 적어 드립니다.

문제 아님

의심했지만 반박되어 걸러낸 것. 걱정하지 않아도 되는 이유를 함께 남깁니다.

의심에서 확정까지, 이렇게 진행합니다

  1. 구조 파악시스템 구조, 외부 입력이 들어오는 곳, 믿을 수 있는 경계를 지도로 그립니다.
  2. 문제 찾기서로 격리된 AI가 공격 유형별로 취약점을 찾습니다.
  3. 반박 검증찾은 후보마다 다른 AI가 틀렸음을 증명하려 시도합니다.
  4. 근거 재확인확정된 항목의 소스 근거를 독립적으로 다시 확인합니다.
  5. 리포트 전달쉬운 말로 정리하고 암호화해 전달합니다.

실력은 숨기지 않고 공개합니다

정답을 아는 연습용 앱에 실제로 돌려 본 결과입니다. 못 찾은 것과 약하게 찾은 것도 그대로 적었습니다.

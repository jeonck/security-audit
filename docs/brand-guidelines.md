# Metacog Audit 브랜드 가이드

## 핵심
- **이름**: Metacog Audit (메타코그 오딧). metacog = 메타인지, "생각을 한 걸음 밖에서 다시 보는 것".
- **한 줄 정의**: 스타트업을 위한 제3자 코드 보안 점검
- **핵심 메시지**: 내 코드는 내가 제일 못 봅니다. 그래서 제3자의 눈이 필요합니다.
- **브랜드 원칙**: 증명하지 못하면 말하지 않는다 (No proof, no claim)

## 포지셔닝
보안 담당자가 없는 스타트업·소규모 팀이 출시, 투자 실사, B2B 보안 심사 전에
"우리 코드, 정말 괜찮은가?"에 근거 있는 답을 얻게 하는 독립 점검 서비스.
자동 스캐너와 달리 찾은 후보마다 별도 검증을 거쳐 증명된 것만 보고한다.

## 증명 장치 (가치를 스스로 증명하는 방법)
| 약속 | 증명 방법 |
|---|---|
| 증명된 것만 말한다 | 모든 후보는 별도 검증 에이전트가 반증 시도 → 살아남은 것만 "확정", 나머지는 "추가확인 필요"로 분리 |
| 실력을 숨기지 않는다 | 취약점이 알려진 연습용 저장소로 탐지력을 측정해 결과 리포트를 그대로 공개 |
| 이해관계가 없다 | 고객 코드를 대신 개발하거나 보안 제품을 팔지 않는다. "문제없음"도 그대로 말한다 |
| 한계를 먼저 말한다 | 점검 범위·실행하지 않은 것·법정 인증 대체 불가를 리포트와 사이트에 명시 |

## 보이스
- 차분하고 단정한다. 공포 마케팅 금지 ("해킹당합니다!" X)
- 과장 금지: "완벽", "100% 안전", "보증" 사용하지 않는다. 검증되지 않은 숫자·고객 후기 사용 금지
- 용어는 쉽게: "확정 / 추가확인 필요 / 기각"을 일관되게 쓴다

## 비주얼
- 색: 네이비(신뢰) + 틸(검증 통과 신호). 토큰은 `index.html`의 `:root`
- 심볼: `assets/logo.svg` — 바깥 프레임 모서리 4개(한 걸음 밖에서 보는 제3자의 시선) + 안쪽 틸 체크(검증 통과). 워드마크는 모노스페이스 "Metacog**Audit**", Audit만 틸. 가로형은 `assets/logo-lockup.svg`
- 글꼴: 본문 시스템 산세리프, 라벨·번호·플랜명 모노스페이스 ("감사 기록" 느낌)
